## Notebook VectorDB_query_RAG 
# RAG with Pinecone and Small LLMs (CPU-friendly)

This project demonstrates how to build a simple Retrieval-Augmented Generation (RAG) pipeline using:

Pinecone Vector Database for semantic search

Hugging Face Embeddings to convert text into vectors

Small LLMs (1B–2B models) that run on CPU, so anyone can practice without a GPU

# Features

Load documents (e.g., PDF, text)

Create a Pinecone vector index

Embed and upload text chunks

Query Pinecone for semantic retrieval

Use a small CPU-friendly model for question answering

# Requirements
A free account on Pinecone
